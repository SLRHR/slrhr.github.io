01 / OVERVIEW

엔트로피만으로 비밀번호 강도를 판단하지 않도록 했습니다.

입력한 비밀번호의 길이와 문자 집합을 이용해 엔트로피를 계산하고, 반복 문자나 연속 문자열처럼 실제로 쉽게 추측될 수 있는 패턴을 별도로 확인합니다. 결과 화면에서는 점수와 함께 부족한 조건과 개선 항목을 보여줍니다.

02 / SCORING

기본 계산과 패턴 감점을 나눠서 처리했습니다.

N^LSearch space
−Pattern penalty
≈Crack time

문자 집합과 길이로 이론적인 탐색 공간을 계산한 뒤, 반복·순차·키보드 패턴처럼 추측 가능성을 높이는 요소를 별도 규칙으로 반영합니다. 이렇게 해서 길이만 긴 비밀번호가 실제보다 높게 평가되는 문제를 줄이려고 했습니다.

03 / PATTERN CHECK

추측하기 쉬운 패턴을 따로 검사합니다.

  • 비밀번호 길이와 사용 문자 종류 확인
  • 엔트로피 기반 이론값 계산
  • 반복 문자와 연속 문자열 검사
  • 흔한 패턴에 대한 감점 적용
  • 예상 크래킹 시간과 개선 항목 표시

05 / RESULT

점수와 개선 항목을 같이 보여줍니다.

화면에는 보안 강도, 엔트로피, 예상 해독 시간과 함께 어떤 조건이 부족한지 표시합니다. 사용자가 결과를 보고 바로 비밀번호를 수정해 다시 확인할 수 있도록 한 화면 안에서 분석 과정을 끝낼 수 있게 만들었습니다.
